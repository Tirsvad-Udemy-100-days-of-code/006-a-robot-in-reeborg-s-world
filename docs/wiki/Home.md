# Reeborg Maze

🌐 **English** · [Dansk](Home-da) · [Bahasa Melayu](Home-ms)

A beginner-friendly Python project that guides a robot through a maze in Reeborg's world by following the right wall, whatever its random start position and heading. It is the final project of day 6 of the Udemy course *100 Days of Code: The Complete Python Pro Bootcamp*.
